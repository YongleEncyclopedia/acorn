# we-mp-rss：微信公众号 → 订阅源

[we-mp-rss](https://github.com/rachelos/we-mp-rss) 用公众号后台的接口把公众号变成 RSS，正文由它在抓取时一并存下。
松果每 10 分钟读一次它的公众号列表，把新加的公众号订阅进「公众号」文件夹（设置 → 微信公众号）。

```
微信公众平台 ──扫码登录──▶ we-mp-rss（Docker，127.0.0.1:8001）──/feed/<id>.xml──▶ 松果（7700）──▶ 阅读 / 入藏
```

## 日常

- 后台：http://127.0.0.1:8001 ，账号 `admin`，密码 `./ctl.sh login`
- 加公众号：后台「添加订阅」→ 按名字搜 → 添加；或贴一篇该号的文章链接。不用回松果操作
- 授权过期（大约几天一次）：后台右上角「扫码授权」，用**自己管理的公众号/订阅号**的管理员微信扫码
- 定时采集：消息任务「松果·定时采集」，`0 7-22/3 * * *`（7–22 点每 3 小时）
- 松果侧：`acorn wechat`（列表）、`acorn wechat sync`（立即同步）

## 两个登录、两条通道

后台里有两种扫码，别混淆：

| | 公众平台（右上角「扫码授权」） | 微信读书（授权管理 → 微信读书） |
|---|---|---|
| 谁能扫 | 管理着某个公众号/订阅号的微信 | 任何微信 |
| 用来 | 按名字搜索、添加公众号 | 定时采集文章和正文 |
| 有效期 | 约 4 天 | 过期后重新扫码 |

- 只要微信读书已登录，定时任务对 `MP_WXS_*` 公众号一律走微信读书：不受公众平台频率管控，正文来自
  weread.qq.com，不会碰到微信的验证页。默认配置下还会把不在书架上的公众号加到你的读书书架（WEREAD_AUTO_ADD_TO_SHELF）。
- 代价：每次只拿每个号**最新一篇**（一次推送多篇时次条会漏），发布时间记成采集时间。
- 公众平台的文章列表接口会被「freq control」（200013）限流，几小时到一天解除；添加公众号时 we-mp-rss
  会顺手用它抓一次历史，被限流时只是这一步失败，不影响定时采集。搜索时别逐字快速输入，每个字都会触发一次搜索。
- 微信读书偶尔拿不到某篇正文（`invalid_content`），这篇在松果里只有标题，不会自动入藏；
  想留就在浏览器里打开原文，用松果的「浏览器入藏」。

## 运维

```bash
./ctl.sh status | logs | restart | upgrade   # upgrade = 拉新镜像后重建，数据在 ./data 不动
```

- 容器跑在 Colima 里（`brew services` 登录时启动，开启了 Rosetta：上游镜像实际是 x86_64）
- 只监听 127.0.0.1：它的 RSS 地址不需要登录，不要映射到局域网
- `.env` 存登录密码和密钥（权限 600，不进 git）；`data/` 是它的数据库和缓存
- 容器启动时会把环境变量打印进 `docker logs`，日志里能看到 `.env` 的内容，别外传
